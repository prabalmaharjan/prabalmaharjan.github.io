This is my first post. Every future article works the same way:

1. Add a new file to the `_posts` folder.
2. Name it `YYYY-MM-DD-short-title.md` — the date in the filename matters,
   Jekyll uses it to sort and generate the post's URL.
3. Add the metadata block at the top (between the `---` lines) — this is
   called "front matter." At minimum you need `layout: post`, `title`, and
   `date`.
4. Write the rest of the article below the front matter in normal Markdown
   (headings, bold text, links, images, code blocks — all supported).
5. Commit and push. GitHub rebuilds the site automatically within a minute
   or two.

That's the entire workflow for adding new articles going forward — no HTML
or design work required.
